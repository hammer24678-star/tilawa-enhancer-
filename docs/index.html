Server Mode · Local Mode

اختر بين المعالجة السحابية السريعة أو الوضع المحلي الكامل الذي يعمل دون إنترنت.

Server Mode
وضع الخادم
المعالجة تتم على خوادم HuggingFace المخصصة — قوة حوسبية كاملة بدون استنزاف بطارية هاتفك.
  • 3 خوادم متوازية — قدرة عالية
  • رفع مجزَّأ للملفات الكبيرة
  • استئناف تلقائي عند انقطاع الخادم
  • تتبع حالة المعالجة في الوقت الفعلي
Local Mode
الوضع المحلي
تشغيل المحركات مباشرة على هاتفك بالـ proot — خصوصية كاملة وعمل بلا إنترنت بعد إعداد أوّلي واحد.
  • Alpine Linux + Python على هاتفك
  • DeepFilterNet 3 aarch64 مدمج
  • تحميل واحد فقط ~200 ميغابايت
  • خصوصية تامة — الصوت لا يغادر هاتفك
